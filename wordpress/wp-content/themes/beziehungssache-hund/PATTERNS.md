# Block Patterns im Theme

Diese Theme-Bausteine sind als native Gutenberg-Patterns angelegt und koennen direkt im Standard-Editor oder Site Editor eingefuegt und angepasst werden.

## So bearbeitest du Seiten

1. Oeffne eine Seite im Block Editor.
2. Fuege unter `Patterns > Beziehungssache Hund` den passenden Abschnitt ein.
3. Ersetze Texte, Bilder und Links direkt im Block.
4. Fuer Formularseiten:
   Das Pattern `Anfrageformular Bereich` setzt nur den redaktionellen Rahmen.
   Den eigentlichen Formularblock fuegst du direkt darunter ein.

## Wichtige Regeln

- Wiederverwendbare Abschnitte nicht als `Custom HTML` einfuegen.
- Bilder immer ueber den nativen `Bild`-Block ersetzen.
- Farben, Abstaende und Typografie kommen aus `theme.json`, nicht aus Inline-Styles.
- Kontakt-, Preis- und Oeffnungszeiten nur mit freigegebenen Stammdaten aktualisieren.
